## Cómo agregar un proyecto nuevo

1. Crear una carpeta con el siguiente número: `03-nombre-del-proyecto/` (minúsculas, sin tildes, palabras separadas con `-`).
2. Poner ahí el código y un `README.md` con qué hace, cómo se ejecuta y el output.
3. Agregar la fila correspondiente a la tabla de arriba.
4. Subirlo:
   ```bash
   git add .
   git commit -m "03: descripción del cambio"
   git push
   ```
